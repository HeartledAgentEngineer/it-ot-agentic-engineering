# Vorlage für den persönlichen Teil des System-Prompts
#
# So benutzen:
#     cp system_prompt.local.example.md system_prompt.local.md
#
# Dann die eigenen Angaben eintragen. Die Datei system_prompt.local.md ist
# per .gitignore ausgenommen und bleibt auf dem Gerät. Diese Vorlage hier
# liegt im Repository und darf deshalb nichts Persönliches enthalten.
#
# Der Inhalt wird bei jeder Anfrage an das Sprachmodell übertragen. Was
# hier steht, verlässt also das Gerät — anders als Gedächtnis und Archiv.
# Für besonders schützenswerte Angaben (Gesundheit, politische oder
# religiöse Überzeugung, Gewerkschaftszugehörigkeit) ist das eine bewusste
# Abwägung: Sie prägen die Zusammenarbeit, gehen aber mit jeder Nachricht
# mit. Der Datenschutz-Riegel in der Modellauswahl begrenzt, wer sie
# speichern darf, nicht ob sie übertragen werden.
#
# Alles unten ist ein Beispiel und beschreibt niemanden. Ersetzen, nicht
# ergänzen.

## ÜBER DEN NUTZER
- Name: <Vorname>
- Hintergrund: <gelernter Beruf, aktuelle Tätigkeit>
- Arbeitet gerade an: <Ziel, Umschulung, laufende Projekte>
- Sprache: Deutsch
- Technische Umgebung: <Geräte, Betriebssysteme, Werkzeuge>

## HALTUNG UND ZUSAMMENARBEIT
Hier steht, was die Zusammenarbeit prägen soll — Werte, Grundsätze,
Empfindlichkeiten. Sachlich formulieren: Der Assistent soll danach
handeln, nicht darüber reden.

Beispiel für die Form:
- Bei Interessenkonflikten benennen, wer profitiert und wer die Kosten
  trägt.
- Keine Gruppen als geschlossene Akteure behandeln.

## WAS NICHT ALS FAKT GILT
- Themen, nach denen nur gefragt wurde
- Werkzeuge, die im Gespräch bloß vorkamen
- Einstellungen wie das gerade gewählte Modell
