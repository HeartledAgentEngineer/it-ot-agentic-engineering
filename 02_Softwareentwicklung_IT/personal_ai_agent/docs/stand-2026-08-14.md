### Vom PC aus

Das Handy hängt per USB, `adb` liegt unter
`C:\Users\sebas\android-sdks\platform-tools\adb.exe`.

**Wichtig bei Tastatureingaben über adb:** Vorher prüfen, ob Termux im
Vordergrund ist. Ist es das nicht, landen die Befehle in fremden Apps —
das ist in dieser Sitzung mehrfach passiert, einmal in WhatsApp.

```bash
adb shell "dumpsys activity activities | grep topResumedActivity"
```

Dateien aufs Handy bringen (Termux-Home ist per USB **nicht** erreichbar,
App-Privatspeicher): `adb reverse tcp:8765 tcp:8765`, auf dem PC einen
`python -m http.server 8765 --bind 127.0.0.1` im Quellordner, dann in
Termux `curl -O http://localhost:8765/<datei>`. So kamen 240 MB
Datenbank in 5 Sekunden herüber.

## 4. Offene Punkte

### Sofort, ein Befehl

Die 16 vorhandenen Erinnerungen haben **noch keine Vektoren** — ohne die
findet die neue Bedeutungssuche sie nie:

```bash
curl -X POST http://localhost:8080/api/memory/vektoren
```

### Ungeprüft

- **Läuft ein lokaler Embedder auf dem Handy?** Sehr wahrscheinlich nein
  (`requirements.txt` enthält weder `sentence-transformers` noch `torch`),
  aber die Log-Zeile beim Start wurde nie gelesen. Seit `92b3c94` ist es
  folgenlos: Ohne lokales Modell wird über `mistral-embed` eingebettet.
- **Log-Spam:** Hunderte „Invalid HTTP request received" pro Minute auf
  Port 8080. Absender unbekannt. Kostet Akku, macht das Log unlesbar.
  Nächster Schritt wäre `netstat` auf dem Handy, während der Server
  **nicht** im Vordergrund läuft.

### Inhaltlich offen

- **`system_prompt.local.md`** enthält nur „Ingenieur". Werdegang,
  Stationen, Qualifikationen fehlen. Das ist die Stelle für Angaben, die
  der Agent immer parat haben soll — nicht das Archiv.
- **Lebenslauf:** Steht nachweislich **nicht** im Archiv. Die Suche findet
  fünf Stellen, in denen darüber gesprochen wurde, darunter wörtlich
  „Lebenslauf möchte ich erstmal nicht schicken" (ChatGPT, 2025-07-09).
  Das Archiv enthält Chatinhalte, keine Dateien.
- **pCloud-Anbindung:** gewünscht, nicht begonnen. Zugang läuft über einen
  Auth-Token (`userinfo` mit `getauth=1`) oder OAuth 2.0.
  Quelle: https://docs.pcloud.com/methods/intro/authentication.html
  Der eigentliche Aufwand ist nicht der Token, sondern PDF/DOCX zu Text auf
  ARM-Android. Der lohnende Anwendungsfall wären die Fotos
  (siehe `brainstorm-foto-kontext.md`), nicht der Lebenslauf.
- **Erinnerungen aus dem Archiv verdichten:** Die Zweiteilung entspricht
  episodischem und semantischem Gedächtnis, aber die Brücke fehlt — es gibt
  keinen Weg, aus 40.627 Nachrichten ein Profil zu destillieren.
